# Is there a token on hand?

Reports whether ladder has stored a token, ready for use in downstream
requests.

## Usage

``` r
ladder_has_token()
```

## Value

Logical.

## See also

Other low-level API functions:
[`ladder_token()`](https://www.r-ladder.com/reference/ladder_token.md)

## Examples

``` r
ladder_has_token()
#> [1] FALSE
```
