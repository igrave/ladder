# Convert lengths to EMU

Convert lengths to EMU

## Usage

``` r
inches(...)

cm(...)
```

## Arguments

- ...:

  One or more numeric values to convert

## Value

A numeric vector of lengths converted to EMU

## Examples

``` r
inches(2, 0)
#> [1] 1828800       0
cm(3, 2)
#> [1] 1080000  720000
```
